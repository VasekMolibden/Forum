# Форум

PHP-форум с регистрацией, темами, ответами, модераторами и отдельной административной панелью.

В списке тем доступны поиск по названию и описанию, фильтр по категории и сортировка по дате, активности или числу ответов. Модераторы и администраторы могут закреплять темы и закрывать их для новых ответов.

## Запуск

1. Запустите MySQL и PHP-сервер (например, Laragon).
2. Откройте форум в браузере. `db.php` создаст базу `forum_db` и таблицы, а также обновит список ролей в существующей базе.
3. Зарегистрируйте обычную учётную запись.

Параметры подключения к локальному MySQL задаются в `db.php`.

## Назначение первого администратора

После первого открытия форума войдите в phpMyAdmin/MySQL и выполните запрос, заменив `your_username` на имя зарегистрированного пользователя:

```sql
UPDATE users
SET role = 'admin'
WHERE username = 'your_username';
```

Затем выйдите из форума и войдите снова. Ссылка «Админка» появится в верхней панели. В разделе пользователей администратор может назначать роли и удалять аккаунты; удаление аккаунта также удаляет принадлежащие ему темы и сообщения. Последнего администратора и собственный аккаунт удалить нельзя. В админке также можно создавать и переименовывать категории; удалить категорию можно только после переноса или удаления всех связанных тем.

При создании и редактировании темы можно выбрать категорию или оставить тему без категории. Закрытые темы доступны для чтения и редактирования, но отправка новых ответов запрещена.

В текущей локальной конфигурации автоматически создаётся демонстрационный модератор `moderator` с паролем `moderator123`. Это не администратор. Для реального развертывания измените демонстрационные учётные данные и не используйте конфигурацию по умолчанию.
